# Employee Management System (EMS)

A web-based Employee Management System developed using Laravel, React, Inertia.js, Tailwind CSS, and MySQL.

## Features

- Employee record management
- Department management
- Position management
- Employee status tracking
- Role-based access control
- Responsive user interface

## Technologies Used

- Laravel
- React
- Inertia.js
- Tailwind CSS
- MySQL

## Installation

1. Clone the repository.
2. Install PHP dependencies using `composer install`.
3. Install JavaScript dependencies using `npm install`.
4. Copy `.env.example` to `.env` and configure your database.
5. Generate the application key using `php artisan key:generate`.
6. Run database migrations using `php artisan migrate`.
7. Start the development servers using `php artisan serve` and `npm run dev`.
